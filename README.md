# E-Furniture Retail Analytics

**Exploratory Data Analysis using Python and Interactive Business Intelligence using Power BI**

## 📌 Project Overview
This project analyzes furniture-related e-commerce data from the Brazilian Olist E-Commerce dataset to understand sales performance, product categories, delivery operations, and customer satisfaction.

## 🛠️ Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Power BI
- Power Query and DAX

## 🔄 Project Workflow
1. Dataset understanding and data-quality assessment.
2. Data preparation and furniture-category classification.
3. Exploratory Data Analysis (EDA) using Python.
4. Interactive dashboard development using Power BI.
5. Business insights and recommendations.

## 📊 Power BI Dashboard
The dashboard contains three pages:

- **Executive Sales Overview** — Sales, revenue, orders, and monthly trends.
- **Product, Category & Item Performance** — Category comparisons, item values, and freight analysis.
- **Customer & Delivery Insights** — Delivery performance, cancellations, and customer reviews.

To use exploratory analysis and interactive visualizations to identify business trends and support data-driven decisions in e-commerce furniture retail.
